# CAPRI // Cyberpunk AI Terminal Overlay

> Un panel de terminal flotante con asistente de IA integrado 100% offline (vía Ollama) y soporte para ejecución de comandos de sistema, diseñado con una estética ciberpunk y adaptabilidad visual dinámica en PyQt6.

## 🚀 Requisitos Previos
1. Python 3.8+ y pip.
2. Ollama instalado con el modelo `llama3.2:1b`.

## 📦 Instalación y Uso
1. Clona el repositorio y entra a la carpeta.
2. Instala dependencias: `pip install -r requirements.txt`
3. Asegúrate de tener tus recursos gráficos (`capri_standby.jpeg`, `capri_executing.jpeg`, `capri_talking.gif`) en la misma carpeta.
4. Ejecuta: `python3 capri_terminal.py`
